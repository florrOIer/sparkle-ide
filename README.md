# Sparkle IDE

> 面向初学者的**便携式 C++ IDE** —— 解压即用，不用安装、不用配置环境变量。
> 基于 Electron 构建，类 VS Code 外壳，内置节点图可视化与洛谷题库。

**当前版本：`1.0.1`**（Windows x64 便携版）· 中文 / English · 浅色 / 深色 · 三套 IDE 风格 · 洛谷看题即可写题

---

## 下载

到 [Releases](../../releases) 页面下载最新的 `SparkleIDE-<版本>-win-x64.zip`，
解压后双击 `Sparkle IDE.exe` 即可，删除文件夹即卸载。

> ⚠️ **文件夹路径要全英文**（可以有空格）。MinGW 的 g++ 根据自身所在位置
> 推算运行时库，路径含中文/全角符号会编译失败。你的**代码项目**放中文路径反而没问题，
> IDE 会自动复制到纯英文临时目录编译。详见 [`⚠️ 使用前必读.txt`](⚠️%20使用前必读.txt)。

## 开箱即有什么

- **预装 GCC 12.2.0**（在 `resources\app\toolchains\` 里）—— 装完就能编译 C++，最高 C++23
- **一键编译并运行** —— 自动找 `int main(`（不靠文件名），自动生成带中文注释的 `CMakeLists.txt`
- **编辑器** —— 错误红波浪线、按内容/文件名搜索（支持正则）、文件树增删改名
- **节点图** —— 画布式流程图，循环体真实嵌套，可运行看 Python 输出
- **插件系统** —— 独立沙箱、默认零权限；自带 OI-Helper 插件（12 个算法可视化）
- **洛谷题库 + 写题** —— 活动栏「书本」图标，按题号/题名/算法搜索，按难度筛选，
  题面完整渲染（公式转可读形式、样例一键复制、可跳浏览器）。**1.0.1 起点开题目后
  右侧直接出现代码编辑器**，自动建 `luogu/<题号>.cpp`，可保存/编译/运行并就地看输出
- **设置面板** —— 活动栏「齿轮」图标：外观、编辑器、工作区、编译、关于五区，
  改完即生效，存于 `%APPDATA%\Sparkle IDE\settings.json`

## 多语言 / 主题 / IDE 风格（1.0.0 新增）

设置 → **外观**：

| 选项 | 取值 |
|---|---|
| 语言 | 中文 / English（切换即时生效，含应用外壳文案） |
| 主题 | 浅色 / 深色（外壳配色 + 编辑器主题同步切换） |
| IDE 风格 | Sparkle 原生 / Code::Blocks / Dev-C++ / Geany |

三套 IDE 风格不只是换配色，**快捷键位按对应软件映射**：

| 风格 | 编译并运行 | 编译 | 运行 |
|---|---|---|---|
| Code::Blocks | `F9` | `Ctrl+F9` | `Ctrl+F10` |
| Dev-C++ | `F11` | `F9` | `F10` |
| Geany | `F9` | `F8` | `F5` |

（选「Sparkle 原生」时不接管任何功能键，保持应用原有快捷键。）

## 想要 G++ 16 / C++26？

活动栏「工具链」→ 下载列表第一项就是 **WinLibs GCC 16.2.0**（约 105 MB），
一键下载后自动解压并识别（本仓库已把附带解压器从 7-Zip 9.20 升级到 24.09）。

选标准时保持「自动」即可，IDE 会按编译器大版本自动挑：

| 编译器 | 自动选用的标准 |
|---|---|
| GCC 15+ | C++26 |
| GCC 14+ | C++23 |
| GCC 11+ | C++20 |
| GCC 5+ | C++17 |

在设置里手动指定标准时，IDE 会先实测编译器认不认这个开关，
不认就沿上面的阶梯往下找，不会把编译器不认识的 `-std` 传出去。

## 仓库里有什么，没有什么

这个仓库是**分发目录**的版本库，不是从源码构建的工程：

| 在仓库里 | 不在仓库里 |
|---|---|
| `resources\app\out\` —— 主进程/预加载/渲染层全部代码 | `Sparkle IDE.exe` 与 Electron 运行时（245 MB+，走 Releases） |
| `resources\app\vendor\` —— 随包解压器 7-Zip 24.09 | `resources\app\toolchains\` —— 预装 GCC 12.2.0（647 MB，走 Releases） |
| `index.js` —— OI-Helper 插件源码 | `locales\`、各种 `.dll/.pak/.bin` 运行时文件 |
| 使用文档、更新日志 | 日志与缓存（见 `.gitignore`） |

也就是说 **Releases 里的 zip 才是完整可运行的分发包**；仓库里是它的代码与文档部分。
