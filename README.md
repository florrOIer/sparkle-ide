# Sparkle IDE

> 面向初学者的**便携式 C++ IDE** —— 解压即用，不用安装、不用配置环境变量。
> 基于 Electron 构建，类 VS Code 外壳，内置节点图可视化与洛谷题库。

**当前版本：`1.1.1`**（Windows x64 便携版）· 中文 / English · 深色主题（4 套预设）· 背景图片 / 视频 · 洛谷题库 · OI-Wiki 速查

---

## 下载

到 [Releases](../../releases) 页面下载最新的 `SparkleIDE-<版本>-win-x64.zip`，
解压后双击 `Sparkle IDE.exe` 即可，删除文件夹即卸载。

> ⚠️ **文件夹路径要全英文**（可以有空格）。MinGW 的 g++ 根据自身所在位置
> 推算运行时库，路径含中文/全角符号会编译失败。你的**代码项目**放中文路径反而没问题，
> IDE 会自动复制到纯英文临时目录编译。详见 [`⚠️ 使用前必读.txt`](⚠️%20使用前必读.txt)。

## 开箱即有什么

- **预装 GCC 12.2.0**（在 `resources\app\toolchains\` 里）—— 装完就能编译 C++，最高 C++23
- **一键编译并运行** —— 自动找 `int main(`（不靠文件名），自动生成带中文注释的 `CMakeLists.txt`
- **编辑器** —— 错误红波浪线、按内容/文件名搜索（支持正则）、文件树增删改名
- **节点图** —— 画布式流程图，循环体真实嵌套，可运行看 Python 输出
- **插件系统** —— 独立沙箱、默认零权限；自带 OI-Helper 插件（12 个算法可视化）
- **洛谷题库 + 写题** —— 活动栏「书本」图标，按题号/题名/算法搜索，按难度筛选，
  题面完整渲染（公式转可读形式、样例一键复制、可跳浏览器）。**点开题目后右侧直接出现代码编辑器**，
  自动建 `luogu/<题号>.cpp`，可保存/编译/运行；**1.0.2 起每个样例旁可一键「测样例」**，
  自动编译、喂入样例输入并比对输出，给出 AC/WA/TLE/MLE/OLE/RE/CE/UKE 八种判定（时限 1 秒、内存 128 MB、输出 4 MB）
- **设置面板** —— 活动栏「齿轮」图标：外观、编辑器、工作区、编译、关于五区，
  改完即生效，存于 `%APPDATA%\Sparkle IDE\settings.json`

## 多语言 / 主题 / IDE 风格（1.0.0 新增）

设置 → **外观**：

| 选项 | 取值 |
|---|---|
| 语言 | 中文 / English（切换即时生效，含应用外壳文案） |
| 主题 | 浅色 / 深色（外壳配色 + 编辑器主题同步切换） |
| IDE 风格 | Sparkle 原生 / Code::Blocks / Dev-C++ / Geany |

三套 IDE 风格不只是换配色，**快捷键位按对应软件映射**：

| 风格 | 编译并运行 | 编译 | 运行 |
|---|---|---|---|
| Code::Blocks | `F9` | `Ctrl+F9` | `Ctrl+F10` |
| Dev-C++ | `F11` | `F9` | `F10` |
| Geany | `F9` | `F8` | `F5` |

（选「Sparkle 原生」时不接管任何功能键，保持应用原有快捷键。）

## 想要更新的 G++ / C++26？（1.1.1 重做）

活动栏「工具链」→ 下载列表第一项就是 **WinLibs GCC 16.2.0**（约 106 MB，7z 压缩），
一键下载后自动解压并识别，**不需要管理员权限**，装在用户目录里，删掉即卸载。

下载器内置 4 条线路（GitHub 直连 + 3 个加速镜像）：前一条失败自动换下一条；
连接上但 **30 秒收不到数据**也会主动断开换线 —— 国内直连 GitHub 最常见的就是
"连上了但不给数据"，光有连接超时是不够的。

选标准时保持「自动」即可，IDE 会按编译器大版本自动挑：

| 编译器 | 自动选用的标准 |
|---|---|
| GCC 15+ | C++26 |
| GCC 14+ | C++23 |
| GCC 11+ | C++20 |
| GCC 5+ | C++17 |
| GCC 4+ | C++14 |

也可以在**状态栏点 `C++ 17` 徽章**（或 `Ctrl+Alt+C`、命令面板「构建：切换 C++ 标准」）
直接改。手动选高了编译器会报 `unrecognized command line option`，
IDE 在「自动」模式下会自动沿着 C++23 → 20 → 17 → 14 → 11 逐级回退，不会一次退到底。

## 皮肤：Minecraft / Blue Archive / 洛谷 / AtCoder（1.1.2 新增）

`Ctrl+Alt+B` → 「皮肤」区，或者命令面板「外观：背景 / 主题 / 透明度」。

| 皮肤 | 长什么样 |
|---|---|
| **Minecraft** | 直角、粗描边、草方块顶条、像素网格，草绿 + 泥土棕 |
| **Blue Archive** | 深蓝底 + 光环青，胶囊按钮，右下角一圈光环，双色柔光 |
| **洛谷** | 洛谷蓝 + 冷灰底，低调 |
| **AtCoder** | 墨灰 + 冷蓝，低饱和 |

三件事说清楚：

1. **没有任何游戏素材**。纹理、描边、光晕全部是 CSS 生成的 ——
   不打包图片，也就没有版权问题，装完包体积不变。
2. **皮肤会盖掉主题**。皮肤是「整套外观」，跟「设置 → 背景」里的四套主题二选一；
   切回「默认」会把你原来的主题重新写回来，不会丢。
3. **强调色仍然可以单独改**。皮肤自带强调色，你在「强调色」里选一个就覆盖它，
   点「跟随默认」回到皮肤自己的颜色。

## 工具箱：下载 + 诊断（1.1.2 新增）

状态栏「🧰 工具箱」或 `Ctrl+Alt+T`。分两页。

**下载**：WinLibs GCC 16.2.0（106 MB）、Python 3.13.7 免安装版、
CMake 3.31.0、testlib.h。下载时显示**百分比 + 实时速度 + 剩余时间**，
每个资源都有多条线路，前一条失败或卡住 30 秒自动换下一条。
全部装到用户目录，不需要管理员权限。

**诊断**：一键检查十项 —— 程序目录是否含中文、编译器、CMake、Python、
工作区、配置目录可写、背景文件是否还在、界面最近报错、磁盘剩余空间。
每项都给「原因 + 下一步怎么做」，可以一键复制报告贴给别人。

## 背景：图片或视频（1.1.1 新增）

`Ctrl+Alt+B` 或命令面板「外观：背景 / 主题 / 透明度」：

| 项目 | 取值 |
|---|---|
| 图片 | png / jpg / webp / gif / bmp / avif / svg |
| 视频 | mp4 / m4v / webm / ogv / mov / mkv |
| 铺法 | 铺满（裁切）/ 完整显示 / 拉伸填满 / 平铺（仅图片） |
| 效果 | 模糊 0~40 px、压暗 0~90% |
| 视频 | 循环 / 静音 / 0.25×~2× 倍速 |
| 透明度 | 面板 0~100%、编辑器 0~100% |

背景媒体走 `sparkle-media://` 私有协议，**支持 Range 流式读取**：
视频可以拖动进度条、边下边播，也不再受"图片不能超过 24 MB"的限制。
这个协议只服务当前选中的那一个文件，不会把任意磁盘路径暴露给界面。

## 主题自定义（1.1.1 新增）

同一面板的「主题」区：**深色 / 纯黑 / 深蓝 / 暖灰** 四套预设（跟「设置 → 背景」
是同一份数据，在哪边改都会同步），外加**自定义强调色**。

强调色只影响按钮、边框、焦点框这些高亮，不在主题变量表里，所以换主题也不会丢。
编辑器底色会跟着主题走（原来固定 `#1f1f1f`，换主题会出现"面板变了、代码区没变"）。

## 仓库里有什么，没有什么

这个仓库是**分发目录**的版本库，不是从源码构建的工程：

| 在仓库里 | 不在仓库里 |
|---|---|
| `resources\app\out\` —— 主进程/预加载/渲染层全部代码 | `Sparkle IDE.exe` 与 Electron 运行时（245 MB+，走 Releases） |
| `resources\app\vendor\` —— 随包解压器 7-Zip 24.09 | `resources\app\toolchains\` —— 预装 GCC 12.2.0（647 MB，走 Releases） |
| `index.js` —— OI-Helper 插件源码 | `locales\`、各种 `.dll/.pak/.bin` 运行时文件 |
| 使用文档、更新日志 | 日志与缓存（见 `.gitignore`） |

也就是说 **Releases 里的 zip 才是完整可运行的分发包**；仓库里是它的代码与文档部分。
