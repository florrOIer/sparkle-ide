# ⚠️ 重要：不要给这个文件夹改中文名字

## 为什么

这个版本**预装了 C++ 编译器**（GCC 12.2.0，在 `resources\app\toolchains\` 里）。
MinGW 的 `g++` 会**根据自身所在的位置**去推算运行时库（`crt2.o`、`libstdc++` 等），
而它**处理不了路径里的中文或全角符号**。

实测对照（同一份编译器）：

| 编译器所在路径 | 结果 |
|---|---|
| `I:\sparkle-bundled\...` | ✅ 正常 |
| `I:\Sparkle IDE Next\.bundled-toolchain\...`（含空格） | ✅ 正常 |
| `I:\...\7. 【推荐】预装编译器 开箱即用\...`（含中文与全角括号） | ❌ 编译失败 |

失败时的报错是「找不到 `crt2.o`」「找不到 `-lstdc++`」，看起来像文件缺失，
**其实只是文件夹名字的问题**。

## 怎么做

- 这个文件夹现在的名字 `7-bundled-recommended` 是纯英文的，**保持原样就能用**
- 如果你想换个地方放，新路径也要**全英文**（可以有空格、可以有数字和半角符号）
- 别放在类似 `D:\我的软件\` 这样的路径下

> IDE 里已经加了保护：如果你真的把它放到了中文路径下，
> 点「一键编译」时会直接告诉你是文件夹名字的问题，而不是丢一串链接错误给你。

## 项目本身的路径可以用中文

上面说的限制**只针对编译器自己所在的位置**。
你的**代码项目**放在中文路径下没问题 ——
IDE 会自动把项目复制到一个纯英文的临时目录去编译，再把产物拷回来。

（这个机制也是实测出来的：MinGW 的 Makefile 同样处理不了非 ASCII 路径，
纯中文、全角括号、全角感叹号都会让它失败，而空格和单引号没问题。）

## 这个版本里有什么

- 预装 GCC 12.2.0：装完就能编译 C++，不用下载也不用配置
- 一键编译：自动找出项目里的 `main`（搜的是 `int main(` 的实际内容，不靠文件名），
  自动生成带中文注释的 `CMakeLists.txt`
- 新建文件 / 文件夹 / 重命名 / 删除
- 搜索：按内容或文件名，支持正则，点结果跳到那一行
- OI 工作台（左栏面板）：洛谷 / VJudge 导题、样例一键运行、对拍、自组比赛、比赛模式
- Git 面板：状态 / 提交 / 分支切换 / 拉取推送 / 历史
- AI 助手：支持国内模型接口，能读改当前文件（Ctrl+Z 可撤销）

## 怎么开始

1. 双击 `Sparkle IDE.exe`
2. 点活动栏的「工具链」—— 应该看到 GCC 12.2.0 显示为「已就绪」
3. 点「资源管理器」右上角的「打开文件夹」，选一个你自己的代码目录
4. 点活动栏的「构建与运行」→ 选中项目 → 「一键编译并运行」

Python 不是必须的，只有「运行 Python 代码」这一个功能需要它。
