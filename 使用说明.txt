Sparkle IDE
======================

怎么打开
  双击「Sparkle IDE.exe」。整个文件夹要一起保留，exe 不能单独拷走 ——
  它需要同目录下的 Electron 运行时（那些 dll 与 locales）。

需要什么环境
  不需要 Node.js、不需要 npm、不需要联网。
  唯一的外部依赖是 Python：只有「运行 Python 代码」这一个功能需要它。
  没有 Python 时其它功能（编辑、文件树、保存、插件、代码分析）都能正常用。

第一次用建议这么试
  1. 点左侧「资源管理器」右上角的「打开文件夹」，选一个自己的代码目录
  2. 点开一个 .py 或 .js 文件，故意写错几处（比如 if 后不加冒号），
     左下角会显示错误数，出错的行会有红色波浪线
  3. 点活动栏的「OI 工作台」，填一个洛谷题号点「导入」，
     右侧会打开题面，样例可以点 ▶ 直接跑
  4. 点活动栏的「Git」，能看到当前分支和改动，写一句提交信息就能提交
  5. 点活动栏的「插件」，里面有示例插件。它们默认零权限：
     要用文件、网络这些能力，插件必须在 sparkle.json 里声明，
     再由你在「设置 → 插件权限」里逐项授权（授权会记住，重启不用再点）

1.1.1 新增的四个东西
  1. 下载 GCC：活动栏「工具链」→ 第一项「一键下载（约 102 MB）」，
     下的是 WinLibs GCC 16.2.0，装到用户目录，不需要管理员权限。
     四条线路自动切换，某条卡住 30 秒会自动换下一条
  2. 切换 C++ 版本：状态栏点「C++ 17」这个徽章（或 Ctrl+Alt+C），
     标准从 C++11 一直到 C++26。选「自动」就按编译器版本挑最高可用的
  3. OI-Wiki：状态栏「📖 OI-Wiki」或 Ctrl+Alt+W。左边是 178 条常用目录，
     右边直接看官网；搜索框先查目录，回车再去官网搜全文
  4. 背景与主题：Ctrl+Alt+B。背景可以选图片，也可以选视频（mp4 / webm 等），
     能调铺法、模糊、压暗、倍速；主题跟「设置 → 背景」是同一套，另有自定义强调色

1.1.2 新增
  5. 皮肤：Ctrl+Alt+B → 「皮肤」，有 Minecraft / Blue Archive / 洛谷 / AtCoder 四套。
     纹理和光晕都是 CSS 画的，不含游戏素材；皮肤会盖掉主题，切回「默认」就恢复
  6. 工具箱：状态栏「🧰 工具箱」或 Ctrl+Alt+T。
     「下载」页能装 GCC 16 / Python / CMake / testlib.h，显示实时速度和剩余时间；
     「诊断」页一键检查环境，红黄绿三色标出来，可以复制报告
  7. 主题包：外观面板底部「导出主题包 / 导入主题包」，存成 json，换机器直接导入

打包信息
  产物同时包含：主程序 + 界面资源 + 示例插件
  这是便携式布局，没有安装向导，删除文件夹即卸载
