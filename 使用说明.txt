Sparkle IDE
======================

怎么打开
  双击「Sparkle IDE.exe」。整个文件夹要一起保留，exe 不能单独拷走 ——
  它需要同目录下的 Electron 运行时（那些 dll 与 locales）。

需要什么环境
  不需要 Node.js、不需要 npm。
  洛谷题库需要联网，编辑、文件树、保存、插件、代码分析都不需要联网。
  唯一的外部依赖是 Python：只有「节点图 → 运行代码」这一个功能需要它。
  没有 Python 时其它功能（编辑、文件树、保存、插件、代码分析）都能正常用。

第一次用建议这么试
  1. 点左侧「资源管理器」右上角的「打开文件夹」，选一个自己的代码目录
  2. 点开一个 .py 或 .js 文件，故意写错几处（比如 if 后不加冒号），
     左下角会显示错误数，出错的行会有红色波浪线
  3. 点活动栏的「节点图」，画几个积木点「运行」，可以直接看到 Python 输出
  4. 点活动栏的「插件」，里面有示例插件；它们运行在独立沙箱里，默认零权限
  5. 点活动栏的「洛谷题库」图标（书本），搜一道题（如 P1001）看看

洛谷题库（新）
  位置：活动栏的「洛谷题库」书本图标。
  搜索：支持题号（P1000）、题名关键字、算法名（如线段树），回车或点「搜索」。
  筛选：按难度下拉过滤（入门 / 普及- / 普及 / 提高+ … 对应洛谷的难度星级）。
  看题：点左侧列表里的题，右侧显示完整题面 —— 题目背景、题面描述、
  输入格式、输出格式、样例与说明。数学公式已转成可读形式，样例一键复制，
  也可以在浏览器里打开原题页面。
  翻页：列表下方分页，每页约 10 题。
  说明：这里只做官方公开题面的只读浏览，不提供提交代码；
  写好的代码还是去 luogu.com.cn 提交。题目版权归洛谷官方所有。

设置（新）
  位置：活动栏的「齿轮」图标 —— 之前的版本这个按钮只是个图标，现在真正能用了。
  编辑器：字号（8–48）、字体、Tab 宽度、自动换行、显示行号、缩略图、
  平滑滚动、光标闪烁方式、空白字符显示。
  工作区：「启动时恢复上次打开的工作区」开关（默认开）。
  编译：默认 C++ 标准 —— 自动 / C++11 / C++14 / C++17 / C++20 / C++23 / C++26。
  关于：查看版本信息、打开数据目录、恢复默认设置。
  所有选项改完立即生效，并保存在 %APPDATA%\Sparkle IDE\settings.json。

编译器：G++ 16 与 C++26（新）
  预装编译器仍是 GCC 12.2.0（在 resources\app\toolchains\ 里），开箱即用，
  最高实测支持 C++23。
  想要 C++26：点活动栏「工具链」，下载列表已换成 WinLibs GCC 16.2.0（约 105 MB），
  「一键下载」会自动解压到用户数据目录并自动识别（解压用的 7-Zip 已随包附带）。
  选中新编译器后，C++26 就真的能编译了。

  自动选标准（按编译器大版本，读的是真实探测结果）：
    GCC 15+ → C++26，GCC 14+ → C++23，GCC 11+ → C++20，
    GCC 5+ → C++17，GCC 4+ → C++14，其余 → C++11
  在设置里手动指定了某个标准时，IDE 会先实测编译器认不认这个开关，
  不认就沿着上面的阶梯往下找第一个真支持的，不会把编译器不认的 -std 传出去。

打包信息
  产物同时包含：主程序 + 界面资源 + 示例插件
  这是便携式布局，没有安装向导，删除文件夹即卸载
